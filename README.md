# big-project
# 午夜禽慌：嘉義廠區逃脫

## 專案簡介

本專案為第一人稱恐怖解謎遊戲。玩家需要在工廠環境中探索、收集道具並完成解謎，以尋找逃脫路線。

本專題使用 Unity 開發遊戲，並整合 MediaPipe 手部追蹤與手勢辨識，透過 Python 與 Unity 之間的 UDP 通訊，將辨識結果應用於玩家控制與遊戲互動。

## 使用技術

- **遊戲開發：** Unity、C#
- **電腦視覺：** Python、MediaPipe
- **通訊機制：** UDP
- **遊戲機制：** 道具與背包系統、環境解謎

## 個人負責內容

- 使用 MediaPipe 實作手部追蹤與手勢辨識。
- 建立 Python 與 Unity 之間的 UDP 通訊機制。
- 參與玩家控制與手勢互動功能的實作。
- 參與冷凍庫關卡、背包及道具相關機制的開發與整合測試。

## 遊戲特色

- 第一人稱恐怖探索與解謎玩法。
- 結合手勢辨識的玩家控制與互動機制。
- 透過道具收集與機關解謎推進遊戲流程。
- 利用場景燈光與音效營造恐怖氛圍。

## 目前開發進度

目前已完成一樓入口至冷凍庫的主要遊玩流程，玩家可以進入冷凍庫並進行相關解謎。

其他場景與部分遊戲流程仍在持續整合中，因此目前版本屬於開發中的專題版本。

## 如何開啟專案

1. 安裝與本專案相容的 Unity 版本。
2. 使用 Unity Hub 開啟本專案資料夾。
3. 等待 Unity 完成資產匯入與編譯。
4. 開啟遊戲入口場景，確認必要的場景與套件設定後執行。

### 手勢辨識環境

準備相容的 Python 環境、必要套件及手部追蹤模型，並啟動 Python 辨識程式，讓 Unity 透過 UDP 接收辨識結果。
